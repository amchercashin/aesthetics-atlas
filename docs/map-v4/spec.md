# Карта 4: туманности и навигация по связям (спецификация)

Статус: реализовано 14.10.2026 (план: [docs/superpowers/plans/2026-10-14-map-v4.md](../superpowers/plans/2026-10-14-map-v4.md), итоги — `docs/map-design.md`, раздел «Версия 4»). Прототип слоя туманностей лежит в [`prototype/`](prototype/), снимки — в [`shots/`](shots/).

## Зачем

Сценарий пользователя: долго сидеть над картой и изучать влияния во всём их многообразии, периодически отдаляясь, чтобы увидеть целое, и приближаясь к интересным областям, или двигаясь по связям от стиля к стилю.

Что мешает в версии 3.1 (замеры на данных 14.10.2026):

- **Влияния почти не видны.** Из 261 связи место на карте получают 147 — по первому родителю (`parents[0]`). Остальные 114 (44%) видны только в крупном плане одного стиля или в слое «Все связи», где превращаются в паутину. Из 102 связей типа «влияние» вторичны 88. 35 вторичных связей длиннее порога `LONG`, 24 перескакивают через две эпохи и больше.
- **Два визуальных канала пустуют.** Вертикаль ничего не значит. Цвет точки — эпоха, но эпоху уже показывает горизонталь.
- **Движение по связям не оставляет следа.** Адрес меняется через `replaceState`, поэтому «Назад» в браузере не работает. Esc возвращает к виду до первого выбора, а не к предыдущему стилю. «Обзор», «Эпоха», «Вся история» и крупный план — отдельные камеры с прыжками между ними.

## Решения

1. **Раскладка древа остаётся.** Сравнение с вертикалью по регионам («потоки») на тех же данных: потокам нужно 70 строк против 25, Европа — 70 стилей из 153, 105 связей пересекают потоки. Древо сохраняет ноль пересечений линий с текстом и разреженность версии 3.1.
2. **Туманности** — группы близких стилей, нарисованные как моря на гравированной карте. На дальнем масштабе 15 туманностей, на обзоре они распадаются на 42 части.
3. **Точки красятся цветом туманности.** Эпоха остаётся на оси и в навигаторе эпох.
4. **Навигация по связям:** дуги влияний с правилами проявления, маршрут, клавиатура, лупа времени, полёт по связи.

## Туманности

### Данные

`content/nebulae.yaml` — редакторский файл, сборка берёт состав только отсюда:

```yaml
- id: modern-symbolism
  name: Модерн и символизм
  color: "#D4537E"          # необязательно; без него — цвет из палитры главной работы (см. «Цвет»)
  parts:
    - id: pre-raphaelites
      name: Прерафаэлиты
      styles: [pre-raphaelites, aesthetic-movement, japonisme]
    - id: art-nouveau
      name: Модерн
      styles: [arts-and-crafts, art-nouveau, vienna-secession]
    # … часть «Символизм»
free: [aboriginal-art, mesoamerican-art, andean-art]   # «свободные звёзды»: стили вне туманностей, явно
```

Валидатор (в `npm test`):

- каждый стиль либо ровно в одной части, либо в `free`;
- все id существуют;
- у части есть хотя бы один стиль;
- новый стиль без туманности — ошибка с подсказкой скрипта: «по связям ближе всего к части X».

### Скрипт-предложение

`scripts/nebulae.mjs` пишет черновик `nebulae.yaml` (или подсказки к нему). Редактор правит имена и состав.

- Граф: все связи `parents`. Вес связи = вес типа × `exp(−Δx / τ)` × `exp(−Δстрок / ρ)`.
  - Веса типов: развитие 1, влияние 0,7, реакция 0,4, возрождение 0,25.
  - `Δx` — разрыв по оси времени в px рабочего масштаба, нормированной на 10 000; `τ = 800`.
  - `Δстрок` — расстояние между строками древа; `ρ = 6`.
- Алгоритм Louvain, разрешение γ = 2. Первый уровень — части, второй — туманности.
- Черновик: [`prototype/scripts/clusters.mjs`](prototype/scripts/clusters.mjs). Состав и имена прототипа: [`prototype/scripts/nebulae.mjs`](prototype/scripts/nebulae.mjs).

На текущих данных скрипт дал 13 туманностей по 6–23 стиля и одиночки. Редактор внёс 7 правок, и получилось 15 туманностей, 42 части и 3 свободные звезды:

- Северное Возрождение → «Ранний Ренессанс»: алгоритм связал его с исламским миром через могольскую миниатюру.
- Искусство Древнего Китая → «Китай и Япония»: алгоритм положил его в неолит.
- Мезоамерика → свободная звезда: в авангард её тянула связь возрождения с мексиканским мурализмом.
- Дарк-академия и коттеджкор → «Коры»: у них только связи возрождения с XIX веком.
- Палеолитическая пластика → «Палеолит».
- «Дальний Восток» выделен из «Древних истоков» в отдельную туманность.
- Туманность «От классицизма к экспрессионизму» (20 стилей) разделена на «Классицизм и историзм» и «От романтизма к экспрессионизму».

Вывод: алгоритм только предлагает состав, утверждает редактор. Связи возрождения через века ненадёжны как признак близости.

### Отрисовка «гравюра»

Образцы — морские карты Блау и Меркатора, адмиралтейские карты XVII–XVIII веков. Реализация в [`prototype/nebula-engraved.js`](prototype/nebula-engraved.js).

1. **Поле плотности** в координатах карты (сетка с шагом 2 px). Вокруг каждого члена — анизотропное ядро, шире по времени (36 × 27). Вдоль ветвей между членами — протоки (полуширина 14), чтобы море было связным.
2. **Рваный берег.** Поле искажается детерминированным шумом (domain warping, сила края 0,42). Берег — изолиния: порог 0,42 для туманности, 0,34 для части.
3. **Острова и проливы.** Под своим членом море гарантировано (радиус 9). Вокруг чужой точки — остров (радиус 12). Между соседними морями зазор 0,2, между частями одной туманности — проливы 0,3.
4. **Water lines** — тонкие линии, повторяющие берег и затухающие к середине моря, по карте расстояний. На дальнем масштабе 7 уровней, на обзоре 7 более частых. Глубже — пунктир глубины. Под линиями — лёгкая отмывка цветом туманности.
5. **Скорость.** Геометрия считается один раз в `init()`: Path2D и холст отмывки в координатах карты. Кадр — `drawImage` и `stroke` готовых путей с трансформацией камеры, поэтому вблизи линии остаются чёткими.
   - Замер исправленного прототипа (встроенный браузер, DPR 2, окно 814 × 921, 153 стилей): подготовка 0,7 с, 101 тыс. точек береговых линий. Кадр при зуме по `requestAnimationFrame`: в среднем 15–20 мс, p95 35–41 мс; тот же прототип с ореолами — 6 мс. Замер «кадр 0,9 мс», который был в первой версии этой спецификации, сделан с ошибкой (см. ниже) и неверен: время вызовов `stroke()` не включает растеризацию.
   - Поэтому на сайте слой кэшируется в битмап: при панорамировании он сдвигается, при зуме растягивается, а перерисовывается с задержкой после остановки. Цель: p95 кадра при панорамировании и зуме ≤ 16,7 мс при DPR 2, подготовка ≤ 1,5 с (лучше в фоне после первого кадра).

### Масштабы и переходы

| Масштаб | Что видно |
|---|---|
| «Вся история» (k ≈ 0,54 обзора) | 15 туманностей-морей, названия разреженными капителями вдоль дуги по оси моря |
| Просторный обзор (k = 1) | 42 части-острова с проливами, названия частей курсивом; подписи главных стилей |
| Эпоха и крупнее (k ≥ 1,9) | туманности уходят в фон (бледная отмывка без water lines), все подписи стилей |

Переходы плавные по `k`: туманность растворяется в части, части бледнеют. Скачков нет.

### Названия

- Spectral курсив с разрядкой, вдоль плавной кривой по главной оси области (SVG `textPath`). Размер зависит от протяжённости моря.
- Названия не перекрывают друг друга и подписи стилей, не выходят за экран.
- Клик по названию — камера на эту область. Наведение — подсветка членов и список в подсказке.

### Цвет

- Цвет туманности — редакторский (`color`). Без него — акцент палитры главной работы туманности, с проверкой контраста с соседними туманностями на карте; при конфликте берётся следующий цвет палитры.
- В прототипе цвета подобраны вручную. Соседние по времени туманности не повторяют оттенок.
- Тёмная тема — та же гравюра: светлые линии на тёмной бумаге (см. [`shots/engraved-far-dark.png`](shots/engraved-far-dark.png)).

### Что доработать по сравнению с прототипом

- **Ошибка прототипа исправлена при подготовке плана.** Упрощение береговых линий схлопывало каждый замкнутый контур в одну точку, поэтому береговые линии и линии глубины вообще не рисовались: на первых снимках видны были только цветной слой с размытым краем. После исправления (функция `rdp` в `prototype/nebula-engraved.js`) это настоящая гравюра: резкий берег и линии глубины. Снимки в `shots/` обновлены; вид отличается от того, который вы выбирали.

- Вблизи курсивные названия частей местами пересекают ветви древа. Их нужно ставить в свободные места или прятать на этом масштабе.
- На дальнем масштабе названия «Классицизм и историзм» и «Сюрреализм и абстракция» идут под крутым углом и теснятся. Нужно ограничить угол дуги и сдвигать подпись вдоль оси моря.
- Маленькие оторванные моря: одиночный член далеко от своей туманности рисуется отдельным пятном. Нужно правило минимальной площади (сливать с ближайшим морем своей туманности протокой или рисовать без моря).
- Ось эпох в прототипе обрезает «От Просвещения к импрессионизму» до «От». Это ошибка основы прототипа; на сайте ось своя.

## Навигация по связям

- **Земля и небо.** 147 главных связей остаются ветвями древа. 114 вторичных рисуются дугами над картой. Правила проявления:
  - на обзоре дуг нет;
  - при наведении на стиль — его дуги, бледно;
  - при выборе — его дуги с подписью типа;
  - внутри лупы — бледные дуги, у которых оба конца в лупе.

  Дуги заменяют слой «Все связи» и отростки длинных связей.
- **Маршрут.** Каждый переход оставляет трек тёмными чернилами и пополняет цепочку «Укиё-э → Японизм → Модерн». Адрес меняется через `pushState`, «Назад» и Esc ведут к предыдущему стилю. Маршрутом можно поделиться ссылкой.
- **Клавиатура.** ←/→ — к предкам и потомкам, ↑/↓ — перебор внутри группы, Enter — перейти, Backspace — шаг назад по маршруту.
- **Лупа времени.** Эпоха в фокусе раскрывается до рабочего масштаба, остальные сжимаются по краям, но остаются на экране. Лупа объединяет «Обзор», «Эпоху» и «Всю историю» в одно непрерывное движение колёсиком. Длинная связь вроде «Греческая классика → неоклассицизм» видна целиком, потому что середина сжата.
- **Полёт по связи.** При переходе камера едет вдоль связи, оба конца в кадре. При `prefers-reduced-motion` анимации нет.

## Фазы и критерии готовности

1. **Маршрут и клавиатура.** «Назад» в браузере и Esc ведут к предыдущему стилю. По графу можно пройти без мыши. `npm test` зелёный.
2. **Дуги влияний.** В обычном режиме одновременно видны только дуги выбранного или наведённого стиля. Видимых пересечений линий с текстом 0 по `scripts/dev/map-geometry.js` при 1366, 1440 и 1920 px.
3. **Туманности.**
   - `content/nebulae.yaml` и валидатор входят в `npm test`.
   - На «Всей истории» подписаны все 15 туманностей без наложений при 1366, 1440 и 1920 px.
   - На обзоре подписано не меньше 90% частей.
   - Вблизи названия частей не пересекают подписи стилей.
   - p95 кадра при панорамировании и зуме ≤ 16,7 мс при DPR 2 (замер по `requestAnimationFrame`), подготовка ≤ 1,5 с.
   - Обе темы проверены снимками.
4. **Лупа времени.** На любом шаге колёсика видна вся ось времени, подписи внутри лупы не обрезаются.
5. **Полёт по связи.** Оба конца связи в кадре всю анимацию. При `prefers-reduced-motion` анимации нет.

## Прототип

Открыть локально:

```bash
python3 scripts/dev-server.py 8765
```

Затем откройте `http://localhost:8765/aesthetics-atlas/docs/map-v4/prototype/`. Масштабы — кнопками «Далеко / Ближе / Рядом» или колёсиком. Тёмная тема — `#theme=dark`. Замер скорости — `#view=mid&perf=1`: результат в `document.body.dataset.perf`.

- `data.js` сгенерирован скриптом `scripts/build-data.mjs` из раскладки сайта и состава туманностей.
- Скрипты в `prototype/scripts/` — черновики с абсолютными путями. Их задача — воспроизвести анализ, а не войти в сборку.


## Уточнения при реализации

- **Дуги.** Вторичные связи и так рисовались по наведению и выбору; добавлены только фоновые дуги на рабочем масштабе. Переключатель «Все связи» остался (в тексте выше сказано «заменяют»).
- **Формат `nebulae.yaml`** — объект с ключами `nebulae` (список) и `free` (список), а не список с `free` на одном уровне.
- **Лупа времени** сделана как краевые желоба: центр — рабочий масштаб, края сжаты (`js/lens.js`).
- **Подсказка для нового стиля** без туманности — по весам связей (`closestPart`), Louvain-скрипт в сборку не входит (черновик в `prototype/scripts/`).
- **Названия на «Всей истории»** ставятся раньше подписей стилей; наборы названий (туманности и части) не показываются вместе.
- **Не сделано из спецификации:** названия туманностей не кликабельны и без подсказки при наведении; контраст соседних туманностей не проверяется (цвета задаёт редактор); p95 кадра при непрерывном зуме в headless-Chrome без GPU 33 мс, цель ≤ 16,7 мс не подтверждена на этом замере (панорама и редкий зум укладываются).
