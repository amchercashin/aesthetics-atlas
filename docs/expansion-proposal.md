# Предложение по расширению охвата

> Расширенная программа от 14.10.2026: [557 кандидатов](../research/expansion/README.md), [правила включения](expansion-policy.md), [порядок внедрения](expansion-workflow.md). Таблица ниже сохраняет раннюю очередь; актуальные приоритеты находятся в исследовательском каталоге.

Дата: 13 октября 2026 года. Основание — [матрица покрытия](coverage.md) и раздел 5.2 аудита.

Это редакторское предложение, а не канон. Каждый узел нужен потому, что закрывает конкретное искажение: пустой регион, слишком длинную стрелку в родословной или обзорную карточку, которая выдаёт целую цивилизацию за один стиль.

Источники в колонке «Кандидаты» на момент написания **не открывались**. Их нужно открыть и сверить до того, как карточка попадёт в атлас. Поиск по похожему названию не заменяет проверку.

## Как добавлять узел

1. Открыть источники. Записать в `content/sources.yaml`, что именно каждый подтверждает.
2. Просмотреть кандидата в главную работу. Проверить атрибуцию и лицензию, указать `role` и `whyRepresentative`.
3. Задать `kind`, `scopeNote`, значение дат (`dateKind`, `approx`) и связи. Связь без источника — `status: unverified` с пояснением в `note`.
4. Запустить `npm run build`, `npm test` и `npm run coverage`. Матрица должна показать закрытую клетку.
