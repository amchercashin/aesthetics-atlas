# Атлас эстетик

Навигатор по визуальным стилям, которые придумали люди: от наскальной живописи до vaporwave, weirdcore и эстетик 2026 года.
152 стиля, их родословная, хронология, главные работы и ссылки для самостоятельного изучения.

- **Карта**: генеалогия на оси времени. Клик по стилю подсвечивает предков и потомков.
- **Хронология**: двенадцать эпох по порядку, каждая со своим пигментом.
- **Каталог**: все стили сеткой работ с фильтрами.
- **Зал стиля**: главная работа с этикеткой, признаки, палитра, родословная, ссылки. Стена окрашивается в палитру стиля.
- **Поиск** (`/` или `⌘K`): по названию, художнику или году.

Сайт статический: HTML, CSS и ES-модули без фреймворков и сборки кода. Собираются только данные.

## Структура

```
content/            исходные данные (YAML), их редактируют руками
  eras.yaml         эпохи
  styles/*.yaml     стили, по файлу на эпоху
  resources.yaml    раздел «Копать дальше»
data/atlas.json     СГЕНЕРИРОВАН из content/ (не редактировать)
js/, css/           сайт
scripts/            сборка данных и проверки
test/               юнит-тесты
```

## Как добавить или поправить стиль

1. Откройте нужный файл в `content/styles/` и добавьте запись по образцу соседних:
   `id`, `name`, `orig`, `start`/`end` (до н. э. — отрицательные), `era`, `domain`, `tier`, `parents` (с типом связи
   `evolved | influence | reaction | revival`; первый родитель — «главная линия»), `summary`, `description`, `traits`,
   `names`, `example`, `wiki`, `links`.
2. Картинки берутся с Wikimedia по точному имени файла. Подобрать кандидатов:
   ```bash
   npm run find -- "запрос"                 # поиск по Commons
   npm run find -- --article "Vaporwave"    # картинки статьи en.wikipedia (вкл. fair use)
   ```
   Файл, который лежит только в английской Википедии (обычно fair use), пишется с префиксом `enwiki:`.
3. Соберите данные:
   ```bash
   npm install
   npm run build
   ```
   Сборка проверяет граф (родители существуют, нет циклов, нет «висящих» стилей), разрешает картинки
   и статьи через API Wikimedia, считает палитры и пишет `data/atlas.json`. При ошибках файл не записывается.

## Проверки

```bash
npm test             # юнит-тесты: шкала времени, раскладка карты, поиск, валидатор
npm run check-links  # внешние ссылки (404 — ошибка)
```

## Локальный просмотр

Сайт рассчитан на работу из подпапки, как на GitHub Pages:

```bash
python3 scripts/dev-server.py 8765
```

Затем откройте `http://localhost:8765/aesthetics-atlas/`.

## Публикация

GitHub Pages из ветки `main` (корень). Все пути относительные, роутинг через `#/…`, поэтому дополнительная настройка не нужна.

## Изображения и лицензии

Все изображения загружаются напрямую с Wikimedia Commons и Википедии, автор и лицензия указаны под каждой работой.
Работы под авторским правом (XX–XXI век) показаны как превью низкого разрешения из английской Википедии на условиях
fair use и помечены. Правообладатель может запросить удаление через issues.
