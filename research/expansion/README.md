# Программа расширения атласа

Зафиксированы **557 кандидатов**, включая 194 авторских языка и 175 коллективных традиций. Сохранены 180 предложений v1, добавлены 377. Исходный снимок проекта — 153 карточки на ревизии `d3f619b3ca715386a1e271e193e3a5276440adb6`, 14.10.2026.

Статусы программы: **30** записей `prepared`, **527** — `candidate`. `prepared` не означает слияние PR или публикацию сайта. [Пилот](../../docs/author-style-pilot.md), [первая региональная порция](../../docs/regional-traditions-batch-01.md), [отчёт второй порции](../../docs/regional-graphics-batch-02.md) и её [рабочий журнал](../batches/02-regional-graphics.json); прочитанные предметные источники перечислены в `verificationSources` и production-реестре `content/sources.yaml`.

Это очередь редакционного исследования. Публикация требует самостоятельного решения по каждой теме. Даты, признаки, представители, изображения и генеалогия не считаются проверенными на основании присутствия записи в очереди.

- [catalog.json](catalog.json) — канонические кандидаты с типом, географией, предложенными признаками, корпусом для отбора, соседями, основаниями и приоритетами. Одна запись занимает одну строку, чтобы последующие решения были видны в небольших diff.
- [sources.json](sources.json) — исходный снимок 72 исследовательских источников и точных пределов поддержки. В этом снимке основной текст прочитан у 38, поисковое извлечение доступно у 33, один — маршрут по коллекции; ссылки есть у 100 кандидатов, у 457 задан только маршрут поиска. Новые проверенные предметные источники добавляются отдельно в `verificationSources` кандидатов и `content/sources.yaml`.
- [relations.json](relations.json) — 45 исторических гипотез, 48 визуальных сопоставлений, 34 предложения контекста. Они не импортируются в историческое дерево.

## Порядок работы

1. Поддержка авторских корпусов, культурных контекстов и раскрываемого уровня карты; пилот из 12 разных случаев.
2. Проверенные тематические партии по 10–20 карточек, сначала P1 (118 тем), затем P2 (418); R (21) требует проверки самостоятельности или полезности узла.
3. Расширение по выявленным пробелам и журнал решений. Число записей не является мерой исторической точности или доказательством полноты.

Для каждого обработанного кандидата сохранять `admissionDecision`: `prepared` (проверенная карточка подготовлена в ветке/PR), `published` (публикация подтверждена после слияния), `merged` (тема объединена с другой карточкой), `deferred` или `rejected`. Для подготовленной, опубликованной или объединённой темы нужны `productionCardId`, `decisionDate`, `decisionNote`, `verificationSources`. Исследовательская запись остаётся с историей решения. Приоритет не заменяет состояние проверки.

```sh
npm run research:check
```

Команда проверяет структуру очереди, источники и соседства отдельно от production-схемы. При появлении ID кандидата в `content/styles/` требуется явно зафиксировать решение. Она не проверяет историческую истинность, не просматривает изображения и не превращает исследовательские ссылки в источники утверждений карточки.

Работа с программой ведётся поверх [PR аудита №1](https://github.com/amchercashin/aesthetics-atlas/pull/1): он содержит актуальные исправления содержания и поддержку собственных SVG-иллюстраций.
